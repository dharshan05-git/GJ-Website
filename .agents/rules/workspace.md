# Workspace Rules

## Working Directory

Always use `D:\WD 2` as the working directory for all commands, file operations, and dev server runs for this project.

- **Never** run `npm run dev` or any other commands from `C:\Users\User\Desktop\WD 2`.
- **Always** run commands from `D:\WD 2`.
- When referencing project files, always use `D:\WD 2\...` paths.
